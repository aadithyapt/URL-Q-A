<h1>🔍 Adaptive Question Answering from Web Content (URL-Q-A)</h1>

<p>This project is a web-based application designed to streamline the process of retrieving precise answers from multiple web sources. Leveraging the power of Large Language Models (LLMs) and LangChain, the tool enables users to input multiple URLs and ask natural language questions. The system responds with accurate, summarized answers along with source context, significantly reducing the need for manual searching and reading.</p>

<h2>🚀 Features</h2>
<ul>
  <li><strong>Multi-URL Support:</strong> Upload and query multiple web pages at once.</li>
  <li><strong>LLM Integration:</strong> Uses LangChain to harness powerful LLMs for natural language understanding and generation.</li>
  <li><strong>Source Summaries:</strong> Provides concise answers with clear references to original sources.</li>
  <li><strong>Streamlit UI:</strong> Clean and interactive front-end for seamless user experience.</li>
  <li><strong>Productivity Booster:</strong> Designed to save time and improve focus by minimizing unnecessary browsing.</li>
</ul>

<h2>🛠️ Technologies Used</h2>
<ul>
  <li>Python</li>
  <li>LangChain</li>
  <li>Streamlit</li>
  <li>OpenAI LLM APIs</li>
  <li>Web Scraping Libraries (e.g., BeautifulSoup, Requests)</li>
</ul>
